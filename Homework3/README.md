# 職光 JobBeam（Homework 3）

求職者與企業相遇的求職平台。職缺頁完整呈現工作內容、工作要求與預設月薪；求職者免費註冊後，直接透過私訊向企業應徵。企業可以刊登職缺、管理應徵狀態，並儲值購買曝光，讓職缺優先被看見。

本專案使用 TypeScript 與 Node.js 內建模組撰寫，採 SSR 與 JSON 檔案儲存，執行時不需要任何第三方套件。

## 功能

- 首頁曝光專區、最新職缺、分類瀏覽與平台統計
- 職缺搜尋：關鍵字、分類、工作型態、地點、月薪門檻與多種排序
- 職缺詳情：工作內容、工作要求、福利、標籤、預設月薪與企業資訊
- 企業頁面、相似職缺推薦與瀏覽次數累計
- 求職者／企業註冊、登入、登出、個人與企業資料維護
- 求職者儀表板：應徵進度、面談邀請、未讀訊息與推薦職缺
- 私訊應徵：一位求職者對一個職缺建立一則對話，企業可回覆並更新狀態
- 企業徵才中心：刊登、編輯、上下架職缺與查看應徵對話
- 錢包儲值與職缺曝光：7／14／30 天方案，進行中的曝光會自動延長
- 管理後台：營運數據、使用者、職缺、交易紀錄、贈送曝光與職缺上下架
- Session、CSRF 驗證、角色權限、登入失敗鎖定與 JSON 原子寫入

## 快速開始

需求：Node.js 20 以上。

```powershell
npm install
npm start
```

開啟 <http://127.0.0.1:3000>。第一次啟動會自動建立 `data/jobbeam.json` 與示範資料。

開發時可以讓 TypeScript 持續編譯，再另開一個終端執行伺服器：

```powershell
npm run dev
node dist/src/server.js
```

## 平台規則

- 註冊：免費，可選擇求職者或企業；企業帳號必須填寫公司名稱。管理員僅由種子資料建立。
- 應徵：只有求職者能應徵公開職缺。送出應徵會建立（或沿用）與企業的私訊對話，應徵訊息就是第一則訊息；已結束的對話可再次應徵並重新開啟。
- 應徵狀態：企業可更新為「已投遞、審閱中、邀請面談、已結束」。
- 儲值：單次 NT$ 100～10,000 的整數，提供 300／600／1200／3000 快速金額；付款方式皆為模擬。
- 曝光方案：7 天 NT$ 299、14 天 NT$ 499、30 天 NT$ 899。購買會從企業錢包扣款；已有進行中的曝光時直接延長期限。
- 管理員曝光：可替任何職缺免費贈送 7 天曝光，不扣企業錢包。
- 曝光效果：搜尋的推薦排序會把曝光中的職缺排在前面；職缺詳情被打開時累計曝光數，按下應徵時累計點擊數。

## 路由總覽

| 區域 | 路徑 |
| --- | --- |
| 公開 | `/`、`/jobs`、`/jobs/:id`、`/companies/:id`、`/assets/app.css`、`/assets/app.js`、`/health` |
| 帳號 | `/login`、`/register`、`/logout`、`/profile` |
| 求職者 | `/dashboard`、`/messages`、`/messages/:id`、POST `/jobs/:id/apply` |
| 企業 | `/employer`、`/employer/jobs/new`、`/employer/jobs/:id/edit`、POST `/employer/jobs/:id/visibility`、POST `/employer/jobs/:id/promote`、`/wallet`、POST `/wallet/topup` |
| 管理 | `/admin`、`/admin/jobs`、`/admin/users`、`/admin/transactions`、POST 管理員曝光與上下架 |

所有 POST 表單都需要帶 CSRF 權杖；需要登入或特定角色的路由會自動檢查權限。

## 測試

```powershell
npm test                # 建置後執行單元測試與系統測試
npm run test:unit       # 只跑單元測試
npm run test:system     # 只跑系統測試
npm run test:coverage   # 加上 V8 覆蓋率輸出
```

- 單元測試涵蓋職缺篩選與排序、分類統計、職缺驗證、私訊應徵、未讀訊息、對話狀態、錢包儲值、曝光扣款與權限檢查。
- 系統測試會啟動真實 HTTP 伺服器，使用暫存資料檔與 Cookie 模擬瀏覽器，涵蓋匿名瀏覽、註冊登入、CSRF、角色權限、企業刊登、購買曝光、求職者應徵、企業回覆、儲值與管理後台。
- 測試資料一律寫入系統暫存目錄，不會污染 `data/jobbeam.json`。

## 資料與環境變數

| 變數 | 預設值 | 說明 |
| --- | --- | --- |
| `PORT` | `3000` | 伺服器埠號 |
| `HOST` | `127.0.0.1` | 監聽位址 |
| `JOBBEAM_DATA` | `data/jobbeam.json` | JSON 資料檔路徑 |
| `SESSION_TTL_MS` | `28800000` | 工作階段存活時間（8 小時） |
| `LOGIN_MAX_FAILURES` | `5` | 連續登入失敗幾次後鎖定 |
| `LOGIN_LOCKOUT_MS` | `300000` | 登入鎖定時間（5 分鐘） |

想重置示範資料時，停止伺服器後刪除 `data/jobbeam.json`，下次啟動會重新建立種子資料。

## 備註

本專案是課程示範平台，金流、儲值與曝光購買皆為模擬流程，不會產生真實交易。Session 存在記憶體中，伺服器重啟後需要重新登入。

本專案使用 **opencode** 協助完成程式開發、測試與文件撰寫。
