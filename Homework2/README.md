## 一、方案簡介

**nqu-campus** 是一套以 TypeScript 撰寫的「金門大學校務系統」示範網站，涵蓋登入、課程查詢、選課、課表、成績、繳費與校園公告。它不依賴任何第三方執行期套件，只使用 Node.js 內建的 `node:http`、`node:crypto` 等模組，並以伺服器端渲染（SSR）直接產生 HTML，讓整個流程可以在沒有資料庫的情況下完整運作。

資料以單一 JSON 檔案持久化，寫入時採用「先寫暫存檔再 rename」的原子式操作，避免中途中斷導致資料損毀。

> **AI 協助聲明**：本專案在 [opencode](https://opencode.ai) 的協助下完成。

## 三、選課規則

選課是本專案的核心，規則集中在 `src/services/enrollment.ts`，依序檢查：

1. 課程必須是**目前學期**且**開放選課**。
2. 不得**重複選課**（含已在候補名單中）。
3. 必須**滿足先修條件**：先修課程需有已公布的及格成績。
4. 不得與已選課程（含候補中的課程）**衝堂**。
5. 不得超過**學分上限**（預設 25 學分）。
6. 額滿時自動排入**候補名單**；有人退選時依序**自動遞補**。

## 四、安全設計

| 項目 | 作法 |
|------|------|
| 密碼儲存 | `scrypt` 加隨機 salt，不保存明文；比對採固定時間 |
| 工作階段 | 隨機 token 存於記憶體，設定 `HttpOnly`、`SameSite=Lax` Cookie |
| Session fixation | 登入成功後廢棄舊工作階段並發給新的 |
| CSRF | 所有 POST 表單內嵌 token，以固定時間比對驗證 |
| XSS | 所有使用者輸入在輸出前一律 HTML escape |
| 授權 | Router 宣告允許角色，服務層再檢查資源擁有者，雙層防護 |
| 登入爆破 | 同一帳號連續失敗達上限後暫時鎖定 |
| 開放轉向 | `next` 參數只接受站內相對路徑 |

## 五、環境需求與安裝

需要 **Node.js >= 20**（開發時使用 22.x）。

```bash
npm install        # 安裝開發相依（typescript、@types/node）
npm run build      # 編譯至 dist/
npm start          # 啟動伺服器，預設 http://127.0.0.1:3000
```

> 執行期**零相依**，不需要安裝任何第三方套件。

### 環境變數

| 變數 | 預設值 | 說明 |
|------|--------|------|
| `PORT` | `3000` | 監聽埠號，`0` 代表由作業系統指派 |
| `HOST` | `127.0.0.1` | 監聽位址 |
| `CAMPUS_DATA` | `data/campus.json` | JSON 資料檔路徑 |
| `CREDIT_LIMIT` | `25` | 每學期學分上限 |
| `CURRENT_TERM` | `115-1` | 目前開放選課的學期 |
| `SESSION_TTL_MS` | `28800000` | 工作階段有效時間（8 小時） |
| `LOGIN_MAX_FAILURES` | `5` | 連續登入失敗幾次後鎖定 |
| `LOGIN_LOCKOUT_MS` | `300000` | 鎖定時間（5 分鐘） |

## 七、專案結構

```
src/
├─ app.ts          路由、認證、CSRF 與錯誤處理
├─ server.ts       HTTP 伺服器啟動
├─ cli.ts          資料檔維護工具
├─ assets.ts       內嵌 CSS 與瀏覽器 JavaScript
├─ config.ts       環境變數設定
├─ types.ts        領域資料型別
├─ core/           HTTP、錯誤、密碼、Session、Router、驗證
├─ db/             JSON 儲存與種子資料
├─ services/       帳號、課程、選課、成績、課表、公告、繳費規則
├─ util/           HTML escape、ID 與序號產生
└─ views/          版面、元件與各功能頁面
test/              端對端測試（登入、選課、成績、繳費）
```
